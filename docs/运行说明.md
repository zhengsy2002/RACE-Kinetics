# 运行说明

本项目采用提供的28,017条新版数据及两份划分文件，不重新生成划分，不读取原始CSV的fold列决定训练与测试。

当前随机和同源性协议均使用约90/10划分：开发集25,215条，固定测试集2,802条，开发集内部十折。

## 服务器准备

将整个RACE-Kinetics-master目录上传到服务器。大模型、ReactZyme原始文件和旧缓存没有复制进新项目。

将原始文件放入本项目，不引用其他项目目录：

```text
data/kcat.csv
data/splits/split_random.csv
data/splits/split.csv
data/pretrain/reactzyme/source/proteins.tsv
data/pretrain/reactzyme/source/reactions.tsv
```

其中 proteins.tsv 对应 cleaned_uniprot_rhea.tsv，reactions.tsv 对应 rhea_molecules.tsv。请实际复制文件，不使用指向外部目录的软链接。

安装依赖并检查输入：

```bash
cd /home/aidd4090v2/zsy/code/RACE-Kinetics-master
python -m pip install -e ".[extraction]"
python run.py --config configs/default.json --stage check
```

仅在需要提取基础特征时检查对应编码器，缺失则自动下载到 data/models/esmc 或 data/models/molformer。完整特征缓存直接复用，不调用编码器；完整编码器不重复下载。模型仓库及固定提交号位于 configs/default.json 的 downloads 部分。不提供单独下载命令。

首次下载需要联网，编码阶段只加载本地文件。必要特征及其身份元数据长期保留。临时写入、下载中间文件、Hugging Face 动态代码缓存、Torch 和编译缓存统一位于 data/tmp/run-进程号-随机标识/，按需创建；正常结束、Python异常、Ctrl+C或正常SIGTERM退出后清理本进程目录。强制杀进程或断电无法保证清理，其他进程正在使用的目录不会被删除。下载失败退出后不保留临时下载片段，恢复网络后重新运行原训练命令。

配置中的数据、划分、缓存、模型及输出路径不得越出项目根目录。

## 完整模型

```bash
bash scripts/run.sh --config configs/default.json --experiments full --stage all
```

默认使用下游种子42、43、44；先运行random，再运行homology。默认上游是固定1:1:1的ER/RP/DIR，DIR屏蔽两侧相同及方向记录冲突，预训练种子42。两种协议及下游三个种子共用该预训练模型。

本次CSV内容及行数变化，默认流程会重新处理ReactZyme、提取特征并预训练，不会把旧的29,204行缓存直接套用到新版数据。若新项目已经完成这些阶段，经过校验后复用，不重复训练已完成的预训练模型。

## 六个实验连续运行

```bash
bash scripts/run.sh --config configs/default.json --experiments all --stage all
```

包含full、no_er、no_rp、no_dir、no_environment、learned_only。也可用逗号指定任意子集。no_environment和learned_only复用full预训练，前三个损失消融分别预训练。

## 不查看测试结果的开发流程

按README依次运行prepare、extract、pretrain、features、validate。内部十折用于开发集评估，当前代码采用配置中明确指定的ExtraTrees参数，不自动搜索参数。

模型配置确定后：

```bash
python run.py --config configs/default.json --protocol both --experiments full --stage fit
python run.py --config configs/default.json --protocol both --experiments full --stage test
```

fit在全部开发集拟合最终回归器；test只评估固定测试集，不在测试集拟合或早停。正式比较时应运行并报告全部预先指定种子，不根据测试结果挑选种子或更换划分。

## 结果口径

- development.json：开发集十折OOF，以及十折均值和标准差。
- test.json：固定测试集整体指标，每个下游种子一份。
- test_summary.csv：固定测试集指标在指定下游种子之间的均值和标准差。

三种统计不能混为同一结果。历史数据参与过模型开发，本轮应如实描述为回顾性留出评估。

## 发布版配置

当前代码只保留 ER、RP、DIR。默认权重为 1:1:1，DIR 冲突屏蔽由 `supervision.direction` 控制。
旧配置中的 `conditional_product`、`study`、`pretraining`、`loss_weighting` 和 `evaluation.save_models` 已删除，不能直接沿用旧配置。请从当前 `configs/default.json` 复制所需本地配置，再填写资源路径。
旧检查点和旧运行记录不再兼容；使用新的结果目录重新训练。预训练中的有效分支公式不变，但删除未使用模块改变了初始化及 Dropout 的随机数消耗，因此旧结果不保证逐位复现。
