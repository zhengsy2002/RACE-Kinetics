# 文件结构

项目目录为 `RACE-Kinetics-master`，Python 包为 `src/race_kinetics/`。

- `results/` 保存预训练权重、最终回归器、预测和评估。
- `data/cache/` 保存处理后的 kcat 表、ESM-C 和 MolFormer 基础特征。
- `data/features/handcrafted/` 直接保存 `handcrafted_features.npz` 和 `feature_manifest.json`。
- `data/features/aligned/` 与 `data/features/matrices/` 按输入身份区分对齐特征及组合特征。
- `data/pretrain/reactzyme/prepared/` 保存排除目标数据重叠后的预训练表。
- `data/models/` 长期保留基础编码器权重、分词器和必要模型代码。
- `data/tmp/run-进程号-随机标识/` 统一保存本次运行的临时写入、下载中间文件及按需创建的运行缓存；运行结束后清理。

运行记录仅在内存中保留；不生成或读取旧 `data/runs/`、`data/audits/` 记录。
缓存元数据用于校验输入身份，不属于训练日志。
不会再预先创建 `data/cache/huggingface/`、`data/cache/torch/`、`data/cache/runtime/`、`data/cache/tmp/`。必要的蛋白、小分子、手工和对齐特征不随运行结束删除。

中断训练保留 `weights/last.pt` 用于按轮续训；预训练完成后删除该文件，并在最佳权重内保存完成状态与配置。
最终 ExtraTrees 的输入身份及训练样本 ID 保存在 joblib 权重内，支持单独运行 `--stage test`。
锁文件只在任务运行期间保留；意外强杀后需确认进程已退出再处理残留锁。

本版本不读取旧 PR 命名权重、旧预训练目录或外置运行记录。请从当前默认配置创建本地配置并从头训练。
现有数据、缓存和结果没有被自动删除。数据或实现变化导致缓存校验失败时，应使用新的缓存目录，或在确认没有运行任务后归档对应缓存并重建。
